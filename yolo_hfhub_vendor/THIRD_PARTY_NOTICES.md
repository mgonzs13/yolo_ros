# Third-party notices

This package vendors `huggingface-hub-cpp`
(https://github.com/agonzc34/huggingface-hub-cpp), an unofficial C++ client for
the Hugging Face Hub, fetched at build time via FetchContent. It is used to
download YOLO models directly from the Hub at runtime.
